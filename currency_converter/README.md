# 划词汇率转换（Selection Currency Converter）

一款轻量级 **Tampermonkey 油猴脚本**。浏览网页时，选中价格即可快速换算为人民币（或你指定的目标货币），无需打开计算器，也无需复制到其他网站。

## ✨ 功能特点

- **两种触发方式**：鼠标选中任意非空文字并松开后，选区附近出现小 `¥` 圆点；鼠标悬停即可尝试换算。也可以直接按 `Alt + C`。
- **轻量浮窗**：就近显示原始金额、换算金额和参考汇率；默认约 3 秒自动关闭，也可以点击 `×` 立即关闭。鼠标悬停在浮窗上时会暂停自动关闭。
- **智能币种识别**：优先识别所选文字中的 `USD`、`EUR`、`HK$` 等显式标识，再结合已保存的网站规则、元素属性、附近文字、页面元数据和域名辅助判断。
- **手动纠正并记住网站**：点击弹窗右上角的币种按钮，可选择正确币种；脚本会保存该网站的设置，也能随时清除恢复自动识别。
- **免费汇率接口与故障切换**：默认使用 Frankfurter；失败后依次尝试 Currency API 的 jsDelivr 和 Cloudflare 地址，无需申请 API Key。
- **本地汇率缓存**：默认缓存 24 小时；全部接口不可用时，如有历史缓存，会使用历史汇率并显示提示。
- **可自定义**：目标货币、快捷键、弹窗停留时间、小圆点大小和位置均可在脚本开头调整。

## 👀 使用示例

在网页中选中：

```text
$22.63
```

鼠标松开后，选区附近出现小圆点 `¥`。将鼠标移到圆点上，或直接按 `Alt + C`，即可看到类似：

```text
$22.63                 USD ?    ×
≈ ¥162.58 CNY
1 USD ≈ 7.1842 CNY
```

> 以上数字仅用于演示，并非当前实时汇率。`?` 表示来源币种是推测结果，可以点击币种手动修改。

如果选中的是 `hello` 等不含数字的文字，**圆点仍会出现**；悬停后提示“未识别到有效金额”。选中纯数字（例如 `5`）也可以触发，但币种可能需要手动纠正。

## 📦 安装方法

1. 在 Chrome、Edge 等浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 下载仓库中的脚本文件（建议命名为 `currency-converter.user.js`），在 Tampermonkey 中导入；或新建脚本，复制完整源码并保存。
3. 确认脚本已启用，刷新需要使用的网页。
4. 选中文字、松开鼠标，尝试悬停小 `¥` 圆点；或者选中价格后按 `Alt + C`。

**升级提示：** 请覆盖原脚本或禁用旧版本，避免多个版本同时运行造成按钮、快捷键或样式冲突。当前脚本未设置基于 GitHub 的自动更新地址，更新时请手动导入新版。

## ⚙️ 常用配置

在脚本开头找到 `CONFIG`：

```js
const CONFIG = {
    targetCurrency: 'CNY',
    hotkey: { alt: true, ctrl: false, shift: false, key: 'c' },
    popupDuration: 3000,
    rateCacheHours: 24,
    requestTimeout: 3500,
    defaultDollarCurrency: 'USD',
    defaultYenCurrency: 'JPY',
    maxSelectionLength: 100,
    hoverDotEnabled: true,
    hoverDotSize: 18,
    hoverDotOffsetX: -30,
    hoverDotOffsetY: 10,
};
```

| 配置项 | 作用 |
| --- | --- |
| `targetCurrency` | 目标币种，默认 `CNY`（人民币） |
| `hotkey` | 快捷键，默认 `Alt + C` |
| `popupDuration` | 弹窗自动关闭时间，单位毫秒 |
| `rateCacheHours` | 汇率缓存有效期，单位小时 |
| `hoverDotEnabled` | 是否启用划词圆点 |
| `hoverDotSize` | 圆点尺寸，单位像素 |
| `hoverDotOffsetX` | 圆点相对选区左侧的水平偏移（负数向左） |
| `hoverDotOffsetY` | 圆点相对选区底部的垂直偏移 |

如果和沉浸式翻译等工具的划词按钮重叠，可以尝试调整 `hoverDotOffsetX`、`hoverDotOffsetY`。

## 💱 币种识别说明

脚本支持识别常用币种标识，包括 USD、CNY、EUR、GBP、JPY、CAD、AUD、HKD、SGD、NZD、KRW、INR 等；选择菜单还提供 CHF、TWD、THB、MYR、PHP、VND、IDR、BRL、MXN 等币种。

**注意：货币符号本身并不总能唯一确定币种。** 例如 `$` 可能代表美元、加元、澳元等，`¥` 也可能代表人民币或日元。对于没有明确标识、也无法从页面信息判断的内容，脚本会使用默认币种并以 `?` 提醒你核实。

金额文本尽量支持常见小数和千分位写法，例如 `$1,299.99`、`€22,63`、`1.299,99 €`；复杂页面或不规则格式仍可能解析错误。换算结果仅供快速参考，不代表支付平台、银行卡或银行的实际结算汇率。

## 🌐 汇率来源

依次尝试：

1. [Frankfurter](https://frankfurter.dev/)
2. [Currency API（jsDelivr）](https://github.com/fawazahmed0/exchange-api)
3. Currency API（Cloudflare Pages 备用地址）

脚本通过 `GM_xmlhttpRequest` 获取对应的币种汇率，通常不需要 API Key；已获取的汇率与网站纠正规则保存在 Tampermonkey 本地存储中。网页选中的原文在浏览器本地解析，汇率请求主要包含币种代码，不会把完整选中文字作为汇率接口参数发送。

## ❓ 常见问题

**选中文字后没有圆点？** 先确认脚本已启用、网页已刷新，并检查是否存在多个版本同时运行。浏览器内部页面（如 `chrome://`、`edge://`）、扩展商店和一些特殊页面可能不允许注入用户脚本；部分复杂网页的选区行为也可能存在兼容性限制。

**为什么选中普通文字也会出现圆点？** 这是刻意采用的简化设计：鼠标松开后只判断是否选中了文字，悬停时才尝试解析金额，从而尽量避免过严的触发条件影响网页兼容性。

**为什么只选中 `5` 也会被换算？** 纯数字没有币种信息，脚本只能从网页上下文或默认值推断来源币种；如不正确，请通过弹窗里的币种菜单纠正。

**为什么汇率不是实时交易价格？** 该脚本定位是网页浏览时的快速参考换算，不用于外汇交易或精确结算。默认缓存 24 小时，接口提供的数据更新频率也可能不同。
