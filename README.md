# 🧩 油猴脚本合集（Tampermonkey Userscripts）

这里集中存放我日常使用和维护的 **Tampermonkey 油猴脚本**，主要解决浏览网页时遇到的小问题，让常用操作更简单、更高效。

每个脚本都有独立目录，包含脚本源码和使用说明，方便安装、更新与后续扩展。

| 脚本 | 功能简介 | 使用方式 | 项目链接 |
| --- | --- | --- | --- |
| 💱 **划词汇率转换** | 选中文字后快速换算外币金额；支持币种识别、汇率缓存和网站币种记忆 | 划词后悬停 `¥` 圆点，或按 `Alt + C` | [使用说明](./currency_converter/README.md) · [脚本源码](./currency_converter/currency_converter.user.js) |

## 🚀 如何安装

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)（支持 Chrome、Edge 等主流浏览器）。
2. 在上方索引中点击需要的 **脚本源码**，进入对应 `.user.js` 文件。
3. 点击 GitHub 的 **Raw（原始文件）**。如果 Tampermonkey 弹出安装页面，确认安装即可。
4. 如果没有自动弹出安装页面，可以在 Tampermonkey 中新建脚本，将源码复制进去并保存。
5. 刷新目标网页，按照脚本的使用说明操作。

> 提示：具体运行范围、快捷键、兼容性和配置方法，请查看各脚本目录下的 README。
